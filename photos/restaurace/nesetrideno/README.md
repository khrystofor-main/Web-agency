# Neseřazené fotky

Sem nahrávejte cokoliv, co najdete pro šablony restaurací — bez ohledu na
koncept a bez ohledu na formát. Roztřídíme a zmenšíme to později.

Když víte, k čemu snímek patří, pomůže krátký název: `vinarna-sklep-01.jpg`,
`steak-grill-detail.jpg`. Když nevíte, nechte původní název, nevadí.
