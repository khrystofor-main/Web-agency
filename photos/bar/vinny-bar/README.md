# Fotky — Regál (vinný bar)

## Hero: překrývající se řada (6 fotek)

Soubory: `01.webp` až `06.webp` v této složce.

**Formát:** `.webp`, na výšku, poměr **2:3**, delší strana do 1920 px,
do ~300 kB.

Fotky leží v jedné řadě, mírně nakloněné a překrývající se — jako
láhve položené v regálu. Text sedí v úzkém sloupci pod nimi. CSS
je ořeže na `2:3`, takže je potřeba, aby hlavní motiv byl uprostřed
a kompozice počítala s tím, že kraje nemusí být vidět.

**Motivy (podle cfg.vinny-bar.js):**

| # | Co | Poznámka |
|---|---|---|
| `01.webp` | Láhve vína v dřevěném regálu | Celek — bohatství výběru |
| `02.webp` | Sklenka bílého vína proti světlu | Barva, jas, průzračnost |
| `03.webp` | Nalévání červeného vína do sklenice | Pohyb, tekutina |
| `04.webp` | Prkénko se sýry a chlebem | K vínu patří jídlo |
| `05.webp` | Detail etikety a vývrtky | Blízko, textura papíru |
| `06.webp` | Hosté u stolu se sklenkami | Atmosféra, společnost |

## Interiér (4 fotky)

Soubory: `interier/01.webp` až `interier/04.webp`.

**Formát:** `.webp`, na šířku, poměr **16:9**, delší strana do 1920 px,
do ~300 kB.

| # | Co |
|---|---|
| `01.webp` | Pult s otevřenými lahvemi |
| `02.webp` | Klenutý sklep se stoly |
| `03.webp` | Regál s lahvemi po strop |
| `04.webp` | Stůl u okna s večerním světlem |

## Styl fotek

Teplý krém, vinná červeň, všechno mírně nakřivo. Měkké světlo, žádné
ostré stíny — jako v přítmí sklepa. Barvy ať táhnou do tepla: okr,
rumělka, tmavě červená. Etikety a sklo, dřevo a papír.
